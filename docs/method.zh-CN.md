# 方法、修正与解释

方法依据为 [Dang（2026）教程](https://doi.org/10.1177/25152459261466637)。英文技术说明及来源链接见 [method.md](../skills/hierarchical-masem/references/method.md)。

## 核心估计

1. 对每个独立参与者样本，以 `metafor::rcalc(rtoz=FALSE)` 计算原始 Pearson 相关的完整渐近抽样协方差。
2. 对全部相关联合进行多层多变量 REML 合并，每种变量对有单独固定均值，随机项按效应行与研究索引。比较 HCS/HCS、HCS/CS、CS/HCS、CS/CS 四种组合；在隐含矩阵有效且拟合收敛的模型中按最小 AIC 选择，并报告 BIC 及同数据、同固定效应条件下适用的嵌套比较。
3. 根据变量对身份对齐合并相关向量及均值估计的协方差，传入 `metaSEM::wls()` 拟合用户指定的观测变量无环 RAM 模型，保持隐含方差为 1。渐近协方差不会再次除以 N。
4. 对研究互不交叉的分类组，在选定结构下分别合并相关，再拟合多组 WLS。整体、逐路径和两两差异均使用明确等值约束的直接目标函数差检验；自由度由独立约束数决定。
5. 工作相关敏感性分析始终保持原完整抽样协方差 V，变化只作用于随机效应工作相关，并传递到路径和整体调节检验。逐研究删除诊断保留主分析选定结构。

## 区间求解

优先使用 OpenMx 原生 likelihood-based 区间搜索；有限数值但区间代码失败或缺失的边界不予接受。原生搜索失败时，固定目标路径或组间差异，重拟合其余参数，求解 WLS 目标函数相对自由最优值增加 χ²₁(.95)=3.8414588 的两个边界。

组间差异只需剖面化两个相关独立组，其余不受限制的组贡献相同的常数。为减少冗余非线性约束，备用求解使用 metaSEM 根据其他参数代数计算残差方差的等价单位方差表示；使用前核对它与原模型的自由目标函数、路径估计和隐含相关一致。各端点仍必须保持单位对角、非负残差方差与正定隐含矩阵。独立矩阵计算再次核对 WLS 目标函数及阈值。

程序保留原生失败代码、实际求解方式、端点拟合对象及 `profile_audit.csv`。搜索次数有界，恢复失败仍显式标记。区间是条件于第一阶段模型的逐项 profile-WLS 区间，未证明其经验覆盖率，也未进行同时覆盖校正。

## 与教程代码的有意差异

| 教程问题／行为 | 本实现 |
|---|---|
| `sum(unique(N))` 按人数数值去重 | 按研究／样本身份累计；示例正确 N=2,377，原代码为 2,208 |
| 示例固定选择 model4 | 每套数据比较全部四种结构，选择合格最小 AIC 模型 |
| 敏感性由完整 V 切换成对角 `1/N` | 始终保留完整 V，并检查第二阶段及整体调节变化 |
| `data_DFSr` 未定义等排版／命名问题 | 验证后的数据作为函数参数显式传递；作者对照仅修改测试副本 |
| 对角约束默认给出 Wald 区间 | 请求并核验 likelihood-based 区间，必要时有界剖面重拟合 |
| 多组代数模型出现负绝对 df | 使用目标函数差及明确约束数，不引用负绝对 df 为理论模型自由度 |
| 两两比较注释写六次、实际三次 | 按实际指定路径 × 组对构造检验族，使用 Holm 校正 |
| 教学后续检验继续探索 | 明确预设／探索性角色；直接报告差异检验，不从显著性差别推断差异 |

作者示例每个效应行 ID 只包含一行，因此 rho 没有同一 ID 内的交叉协方差可改变；有效变化来自研究层面的 phi。每研究仅一个样本的亚组在 rho=phi=0 时不能分别解释两层对角异质性方差。

## 适用性与结论边界

完整相关矩阵、样本独立性、相同样本内一致的 N、构念方向及报告对应关系必须有依据。程序不自动补齐相关、修复非正定矩阵或改变数据以获得拟合。N≥5 是 `rcalc()` 输入下限，不是充分样本量保证。抽样协方差基于 Pearson 相关的大样本正态理论；复杂抽样、秩相关、偏相关或信度校正相关需要其他有依据的协方差模型。

相关路径表示条件关联；研究层面调节不提供个体因果证据。非显著不等于等效，饱和模型完美拟合不能支持理论。整合的工作模型选择、第二阶段与多组检验流程尚缺系统模拟验证，推断未整合模型选择不确定性。小研究数和边界方差需限制解释。缺失矩阵、连续调节及重叠样本应使用另外验证的方法，不能擅自归类、填零或按独立样本处理。
