# 计算验证记录

[English](README.md)

v0.2.0 本地验收在 macOS、R 4.6.0 及全部 46 个锁定依赖上完成。[computational-validation.json](computational-validation.json)记录检查数量、来源身份、数值核对和适用范围。公开记录不包含作者原始输入文件或个人本地路径。

- **教程验收**：23 组数值／输入检查；当前核验程序也通过了 v0.1.0 归档兼容检查，覆盖作者代码关键数值对应、人数累计、协方差顺序、行重排、变量改名、直接差异、多重检验、欠识别、不收敛、不支持的数据、归档代码重跑与结果篡改。
- **区间验收**：5 个主路径、15 个亚组、3 个两两差异及 15 个敏感性区间全部成功。7 个区间使用备用剖面求解，14 个端点拟合经独立计算核对。两种备用求解器也能在 2e-5 容差内复现原生成功区间。
- **公开包验收**：5 组合成示例数值检查、6 组命令行／复现检查、5 组配置检查、16 项 HTML 检查和 11 项报告表述检查无须作者材料即可运行。示例包含 8 项研究、10 个虚构独立样本，N=2,083，包含两个人数同为 169 的独立样本。

准备好锁定环境后，在克隆仓库内运行：

```sh
python3 tools/validate_package.py
python3 tools/run_public_checks.py --workdir test-output
```

仅在需要恢复依赖时加 `--setup`。检查脚本在新工作目录中保留日志、JSON 报告和合成分析结果。可选的 [GitHub Actions 模板](../docs/github-actions.example.yml)支持推送时检查包及手动执行锁定 R 合成套件。如需在自己的仓库启用，请复制到 `.github/workflows/`。本地通过不代表其他远端环境／平台也已通过。

作者基准按[入门指南](../docs/getting-started.zh-CN.md)中的 `--tutorial-data` 命令运行并核验校验值。随后向 `tests/acceptance.R` 传入技能目录、`check` 返回的环境路径、运行目录、报告 JSON 路径及原 XLSX 路径。`tests/author_reference.R` 另需用户提供包含原 R／XLSX 的目录，仅在测试副本中应用限定修正，保留原文件及日志。

本验收证明指定案例的计算可复现，不能替代模型选择及多组推断的覆盖率、第一类错误率、功效或一般统计性质验证。缺失矩阵、连续调节和重叠样本尚不支持；未来数据上的优化或区间失败仍须保留。

[v0.1.0 记录](v0.1.0.json)保留此前版本的验收结果。
